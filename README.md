# Taller 6 - GUIs con Swing y Java2D

## Cómo ejecutar

La aplicación se debe ejecutar desde la carpeta raíz del proyecto, porque las imágenes se cargan desde `./imagenes/`.

### Eclipse

1. `File > Import > General > Existing Projects into Workspace` y seleccionar la carpeta del proyecto.
2. Abrir `uniandes.dpoo.swing.interfaz.principal.VentanaPrincipal`.
3. Clic derecho > `Run As > Java Application`.

### Terminal

```bash
javac -d bin $(find src -name "*.java")
java -cp bin uniandes.dpoo.swing.interfaz.principal.VentanaPrincipal
```
